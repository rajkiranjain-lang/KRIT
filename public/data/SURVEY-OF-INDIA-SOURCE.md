# READ60 India Geography Source

Source: Survey of India — Administrative Boundary Database, Entire Country up to District Level with HQ (OVSF/1M/7).

The web map files in this directory are web-optimized GeoJSON derivatives generated from the supplied official shapefile dataset. The source shapefile remains the authoritative source. State boundary records explicitly marked as disputed in the supplied dataset are not included in the interactive state selection layer.

Files:
- `india-states.geojson` — 36 state/UT boundary features for the interactive top-level map.
- `india-districts.geojson` — 810 district boundary features from the supplied dataset.

Original source package supplied for READ60 development by the project owner.
